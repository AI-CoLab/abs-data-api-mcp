Australian Bureau of Statistics · Data API (beta)

What the ABS Data API actually serves

A map of the corpus built by querying it, not by reading its metadata.

ABS publishes a content constraint for every dataflow. Multiplying its dimension values together implies a corpus far larger than the one you can retrieve, because those values are per-dimension marginals, not real key combinations. The endpoint designed to settle this — detail=serieskeysonly — returns malformed JSON, so this catalogue was built by pulling data and recording only what came back.

Each row is a claim made by the ABS user guide or the published OpenAPI specification, checked against live behaviour.
Source: data.api.abs.gov.au/rest
